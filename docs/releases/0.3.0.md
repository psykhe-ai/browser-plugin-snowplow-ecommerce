# v0.3.0

## Fixed

- Removed the unnecessary Node 20 engine requirement from the published browser plugin. Storefront projects can install the package without this engine warning, including projects using Node 14.17.3 and npm 6.14.13.
- Clarified that Node 24.x is used to build, test, and publish the package, while the plugin runs in the browser.

## Upgrade

Install `@psykhe-ai/browser-plugin-snowplow-ecommerce@0.3.0`. No tracking integration changes are required; the browser APIs and event payloads are unchanged from 0.2.0.
